正式回显；72 条预热回显独立保留并排除，两份目标各通过 15 个传输探针。

核对设备 base APK 哈希。启动 ID 不重复，模拟器 boot ID 不变，无缺测或重叠运行。

三对升高，不可仅用默认模式改善值宣布整体提速；键盘稳定模式重新挂载也有显著升高的
两对。保留全部原始阶段时间用于定位后续重复工作，不能假定所有升高都来自噪声。

本实验是语义动作合成输入到 draw 回调，不是物理输入、GPU 呈现时间、冷启动或手机 FPS。
每组只有四个启动对，同一启动内的三条回显不是三个独立设备实验。面板重组包括 SetText、
提交和输出；旧／新回显可见检查仍包含 semantics／idle 等待。
