# 419636a：终端行测量节点替换与 IME 基准

来源：[Terminal Production Viewport Benchmark run 37276183224](https://github.com/navy2016/rikkahub-tool-ui-enhance/actions/runs/37276183224)；
SHA：`419636a89450fe438848e96860d1d7da2338d6fc`；协议：`production-viewport-v2`。

## 变更

- 将 eager 回退的每行 `Box + Modifier.layout + DisposableEffect` 替换为挂在现有 `Text` 上的
  `LayoutModifierNode`。
- 保留旧包装层的测量语义：去除最小约束后测量 Text，再恢复父约束最小宽高，TopStart／RTL
  放置和自然行高不变。
- 行高缓存仍只保留标量和 owner／metric／Text 身份；旧 owner 的 `onDetach` 不会删除新 owner
  已登记的同一稳定 ID。
- 固有尺寸查询不写入测量缓存；节点池化、替换、字体／密度／方向变化都会重新测量。
- 默认 `CHUNKED_LAYERS`、虚拟历史显式入口、IME 回退、状态栏／KEYS、PTY 和选择语义不变。

10k `lazyHistory` 的键盘显示／eager 回退阶段为 `6122.77 ms`，显式 retry 为 `289.87 ms`；
宽度计算只有 `0.55 ms`。这说明宽度重复扫描已不是主项，剩余成本主要在完整 eager 回退的
行树测量／布局与 IME 交接。该结果来自独立 Runner，不能与 `64df33d` 或更早 Runner 的数值
计算严格前后提升百分比。
